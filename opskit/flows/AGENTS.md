# opskit/flows — flow template library

- Follow `docs/ai-workflow/rules/07-pieces-flows.md`. One folder per template: `flow.json`, `README.md`, `test/`, `CHECKLIST.md`.
- No real IDs, keys, emails or sheet URLs in `flow.json` — placeholders only.
- A template is done only after importing and passing its sample run on a fresh CE stack.
